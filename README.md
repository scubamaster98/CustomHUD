# About

CustomHUD is a HUD mod for old versions of PAYDAY 2. (primarily for u37.1)

Originally fixed and fully functional since 12/02/2024.

CustomHUD should work on versions newer than u37.1 just fine. If it doesn't, it's recommended to use the version from the "compat" branch. On even newer versions it's best to ditch this for WolfHUD or something else, there won't be any support for those versions.
There are more branches for this mod, made to support other older versions of the game.

In short, this HUD is potentially compatible from u0+.
