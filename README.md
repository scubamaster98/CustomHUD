# About

This is the compatibility branch of CustomHUD, it is identical to the original fixed version from 12/02/2024 aside from a few fixes or file name changes. This is meant for versions that might not work with the base branch. This will most likely not get any major updates.

CustomHUD is a HUD mod for old versions of PAYDAY 2 (primarily for u37.1)

It should work on every other version above it just fine.

Currently incompatible with u1-u23.
